Architecture
  Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).
  Why did the backend use a NoSQL MongoDB database?

    Express was used for static HTML, and handling routing. JavaScript for dynamic client-side
    interactions, and Angular to create a SPA for the application's admin. MongoDB was chosen because
    of its ability to handle flexible, and diverse trips.

Functionality
  How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces?
  Provide instances in the full stack process when you refactored code to improve functionality and efficiencies, and name the benefits that come from reusable user interface (UI) components.

    JavaScript is a programming language, whereas JSON is a means of storing data. JavaScript Object
    Notation (JSON), is compatible with a number of programming languages and technologies. Because of
    this flexibiility, it was used to transfer data between the front-end and back-end of the application.
    Originally, the application displayed various pages through the usage of base, static HTML. I 
    refactored repetitive parts such as the header, and footer using handlebars to make the respective
    HTML files more concise and brief. 
  
Testing
  Methods for request and retrieval necessitate various types of API testing of endpoints, in addition to the difficulties of testing with added layers of security. 
  Explain your understanding of methods, endpoints, and security in a full stack application.

    I used Postman to test various GET, POST, and PUT requests throughout the application. Additionally,
    token-based authentication was implemented using JWT, to ensure data protection. Methods define
    the type of HTTP request, endpoints specify the URL path for resources, and security involves
    authentication such as JWT tokens for encryption.
